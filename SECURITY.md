# Security policy

## Scope

This policy covers the public repositories in the
[craftLayer-studio](https://github.com/craftLayer-studio) organization and the
sites they publish, including <https://craftlayer-studio.github.io/> and
<https://craftlayer-studio.github.io/industry-demos/>.

The concept demos are static, fictional sites. Their forms do not send data to a
server, so reports about them are most useful when they concern the code itself
(for example cross-site scripting or a vulnerable dependency).

Third-party services we link to (for example GitHub, a hosted form provider or
Scriptly) are out of scope; report issues with them to their owners.

## Reporting a vulnerability

Please report privately. Do not open a public issue, discussion or pull request.

1. **Preferred:** use GitHub private vulnerability reporting on the affected
   repository (**Security** tab, then **Report a vulnerability**).
2. **Alternative:** email [sh20raj@gmail.com](mailto:sh20raj@gmail.com) with the
   subject line `Security: <repository name>`.

Include the affected repository and URL, a description of the issue and its
impact, and steps to reproduce it.

## What to expect

We will acknowledge your report, investigate it and keep you informed of
progress. Once a fix is released we are happy to credit you, if you wish.

We do not run a bug bounty programme and cannot offer payment for reports.

## Please do not

- Access, change or delete data that is not yours.
- Run denial-of-service, spam or social-engineering tests.
- Publish details before a fix is available.
