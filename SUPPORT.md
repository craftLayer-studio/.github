# Getting help

| You want to | Go here |
|---|---|
| Report a bug in one of our public repositories | Open an issue in that repository using the **Bug report** form |
| Suggest an improvement | Open an issue using the **Feature request** form |
| Report a security vulnerability | Follow [SECURITY.md](SECURITY.md); never use a public issue |
| Discuss a new project with the studio | [craftlayer-studio.github.io/contact](https://craftlayer-studio.github.io/contact/) |
| Ask anything else | Email [sh20raj@gmail.com](mailto:sh20raj@gmail.com) |

Issues are for the code and content in these repositories. We cannot provide
general programming help or support for third-party products through issues.

This is a small studio, so responses are best effort. We read everything.
