# craftLayer-studio/.github

This repository holds the public organization profile and the default
community health files for every repository in the
[craftLayer-studio](https://github.com/craftLayer-studio) organization on GitHub.

| Path | Purpose |
|---|---|
| `profile/README.md` | The profile shown on the organization page |
| `CONTRIBUTING.md` | How to report issues and propose changes |
| `CODE_OF_CONDUCT.md` | Contributor Covenant 2.1 |
| `SECURITY.md` | How to report a vulnerability privately |
| `SUPPORT.md` | Where to get help |
| `.github/ISSUE_TEMPLATE/` | Default issue forms (bug report, feature request) |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull request checklist |

GitHub uses these files for any repository in the organization that does not
define its own version.
